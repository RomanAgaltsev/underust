# Rust 1.98 (1.98.0 2026-08-20, 1.98.1 2026-09-03)

The release underust pins as its stable floor.

- Lifetime coercion: shortening a `&mut` lifetime when unsize-coercing, even in an
  invariant position (`Cell<&'long mut i32>` to `Cell<&'short mut dyn Send>`)
  -> candidate | lifetime
- Stricter `repr(transparent)` validation
  -> candidate | layout
- `transmute()` size checking corrected
  -> candidate | layout
- Two runtime-symbol lints (deny-by-default for invalid, warn for suspicious), covering
  `memcmp` and `strlen`
  -> candidate | unsafe
- Floating-point algebraic operations stabilised
  -> candidate | edges
- Substring and subslice range methods stabilised
  -> no action
- `core::ffi::c_void` as a return type now warns
  -> no action
- ARM Thumb targets promoted to Tier 2; PowerPC64 GNU/Linux and AArch64 PAuth added at Tier 3
  -> no action
